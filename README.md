# 3ro.io

Public landing page: monochrome suit/3ro point-cloud reveal, optional colour portrait and an outward particle explosion on entry.

Hold 3 + R + O together, or use the mobile 3-2-2 knock rhythm. Course entry navigates to a separately authenticated private host. This public repository contains no course lessons, learner records, account data or credentials.

GitHub Pages publishes this repository root. Local preview: python -m http.server 8790 --bind 127.0.0.1.
